Foundations

The atoms everything else is built from.

Six things define the look and feel of every Forge surface: color, typography, spacing, radius, motion, and iconography. Get these right and the rest of the system enforces itself.

Color

Charcoal for structure. Ember for action and energy. Iron and cream for everything in between. Semantic colors are reserved for status (success, warn, danger) — never for decoration.

4px base unit, scaled non-linearly to keep meaningful gaps recognizable. Radius is mid (10px) by default; pills (full-radius) for tags and toggle pills only.

Motion

Fast. Tactile. Never showy. Default duration 150ms; entry transitions up to 220ms; nothing exceeds 300ms. Spring is acceptable for sheet/modal reveals; everything else is ease-out.

Iconography

One icon set, used consistently. Outline style at 24px on toolbars and tab bars, 20px inline with text. Stroke 1.5px. The icon set is implementation-agnostic (Tabler, Lucide, or Phosphor light all qualify); pick one in build kickoff and never mix.

Patterns

How components combine.

Form validation

Validate inline on blur, never on every keystroke. Errors appear below the field in red. Submit is enabled until form is touched and invalid; once invalid, it disables and a top-of-form summary appears for screen readers.

Confirmations & destructive actions

Anything destructive (delete, refund, transfer client, end session) requires a one-tap confirm in a bottom sheet. The destructive action is the right-side button, in danger style. Cancel is the left-side ghost button. The sheet must name the thing being acted on ("Delete Maya Khoury's profile?"), not just the verb.

Live mirror

When a PT is logging a session, the client device shows a synchronized read-only view of that session. Every newly logged set animates in (4px slide + opacity). A small pulsing ember dot in the header indicates "live". Mirror is the single most important real-time pattern — invest engineering rigour.

Offline-first

Every write the PT performs (logging, body metric, payment mark-cash) saves locally first, sync second. Offline state is always visible: a small persistent ember chip in the header reads OFFLINE · 3 to sync. Never a modal.

RTL & Arabic

Arabic is a launch language. Every layout flips for RTL — including chevrons, leading icons, and progress directions. Body copy is set in Arabic with the same Inter family or a paired Arabic face decided at kickoff (Tajawal is a fine pairing). Number direction follows locale: Western digits in Lebanese Arabic, can switch to Eastern for some users via a setting.

Accessibility

Non-negotiable.

WCAG 2.2 AA across web and mobile. The list below is the minimum bar.

  • Touch targets minimum 44×44 pt (iOS) / 48×48 dp (Android).
  • Color contrast ≥ 4.5:1 for body text, ≥ 3:1 for large text and icons.
  • Color is never the sole indicator of state — pair with text or icon (badge dots ✓ ! ●).
  • Focus rings visible on every interactive element (3px ember outline).
  • Dynamic type supported — text scales without breaking layout up to 130%.
  • VoiceOver / TalkBack labels on every actionable element. Decorative icons are aria-hidden.
  • Form labels never collapse into placeholders alone — labels stay visible.
  • Errors announced to screen readers via aria-live="polite".
  • RTL fully mirrored: chevrons flip, leading/trailing icons swap, progress bars fill the other way.
  • Motion respects prefers-reduced-motion — animations shorten, no parallax, no auto-play.
